Quantium Software Engineering Virtual Experience
Completed as part of Quantium's Software Engineering Virtual Experience Program on Forage.
What I built
An interactive Dash application allowing a client to dynamically assess how price changes affect sales volume and profitability. Built in Python with a CSS-styled interface designed for non-technical stakeholders.
What the project covered

Full-stack development with Python and Dash
Data visualisation and interactive UI design
Automated test suite and bash script for CI/CD fundamentals
Client-focused design for non-technical users

Status
Completed virtual experience project. Forked from the Quantium starter repo provided by Vagabond Systems via Forage.
